# FinPay

AI-powered Personal Finance Platform.

## Goal

FinPay is a modern personal finance application that helps users understand and improve their financial habits using artificial intelligence.

## Tech Stack

### Android

- Kotlin
- Jetpack Compose
- MVVM
- Room
- Hilt

### Backend

- Java
- Spring Boot
- PostgreSQL
- Redis
- Docker
